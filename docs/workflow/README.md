# Repository Workflows

This directory contains active repository workflows for governed, slice-based agent work.

Root `AGENTS.md` and `QUALITY.md` remain authoritative. A workflow is planning and routing material; it does not authorize implementation until the user runs the repository's explicit workflow execution command.

## Active Workflow

- [workflow.md](workflow.md) - skill landscape expansion workflow for governance skills, role routing, handoff rules, conflict auditing, quality gates and ADR alignment.

## Execution Rule

Use `workflow execute` only when the active workflow should be executed through the configured subagent or role-review process.
