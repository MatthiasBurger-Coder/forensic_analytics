# Role Ownership

| Role | Workflow Responsibility |
|---|---|
| Senior Requirement Engineer | Requirement interpretation, EPIC drift, non-goals and assumptions |
| Senior System Architect | ADR, arc42, hexagonal boundaries and service ownership |
| Senior Java Backend Developer | Repository-source configuration, Liquibase, PostgreSQL adapter and tests |
| Senior React Frontend Developer | Database Settings UI, frontend state, API adapter integration and frontend tests |
| Senior UX Designer | Settings workflow clarity, accessibility and operator feedback states |
| Senior Tester | Regression strategy, targeted tests and full quality gate |
| Data Ownership And Persistence Steward | One-writer model, metadata ownership and H2 retirement policy |
| Senior Analysis Storage Architect | Schema responsibility, metadata/provenance preservation and storage risks |
| Senior DevOps Engineer | Docker Compose, runtime wiring and dependency verification impacts |
| Security And Threat Modeling | Credential, network, diagnostic and private path leakage review |
| Observability And Runtime Diagnostics | Health/readiness and safe failure reporting |
| Contract-First API Steward | Public Settings API and repository-source configuration handoff |
| ADR Steward | PostgreSQL decision record and ADR-0023 supersession notes |
| Quality Gate Orchestrator | Required command selection and failure classification |

No callable subagents were used during workflow creation. The repository role
files and skills were applied as local review checklists.
