## Slice Guardrails

- Shared contracts must be fixed before parallel implementation starts.
- Every slice starts with read-only verification.
- Every implementation slice gets targeted tests before broader quality gates.
- Parser, AST, Joern execution, BTM generation, replay engine, graph engine and UI work are excluded.
- WildFly remains a hardening scenario, not the first functional test.
