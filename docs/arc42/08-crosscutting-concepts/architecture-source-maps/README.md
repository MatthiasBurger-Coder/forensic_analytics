# Architecture Source Maps

## Root Classification

`docs/arc42/08-crosscutting-concepts/architecture-source-maps/` is the
architecture source-map root after the former loose `docs/architecture/` root
was dissolved. It contains service-boundary maps, migration maps,
current-state records and legacy-reference classifications that workflows and
arc42 governance still use as source evidence.

Authoritative arc42 chapter outputs remain the checked section files and
owning companion directories under `docs/arc42/**`. This source-map root must
not be treated as newer arc42 output when an equivalent checked arc42 document
exists.

Do not replace these files with pointer stubs unless a later dedicated
architecture-document consolidation workflow verifies authoritative copies,
updates references, preserves ADR traceability and avoids claiming
implementation or deployment readiness from documentation moves alone.
