# EPIC Requirement Sources

## Root Classification

`docs/epics/` is the requirement source-input root. It holds versioned EPIC
documents that requirement, workflow and arc42 governance read as product
baseline evidence.

EPIC source files remain here. Requirement alignment and architecture
interpretation outputs belong under
[`../arc42/01-introduction-and-goals/requirements/`](../arc42/01-introduction-and-goals/requirements/).
Do not move or replace the EPIC source files with pointer stubs unless a
dedicated requirement-governance workflow updates the skills, workflow rules
and references that explicitly read `docs/epics/**`.
